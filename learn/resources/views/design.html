Design system

renox.rs's tokens, fonts and patterns for a course. Chapters sit on paper; the header, footer, hero and code panels are dark in both modes. Use the toggle in the header to see the other mode.

The colour roles in the current mode. Every colour comes from a token; nothing below the tokens in learn.css defines one.

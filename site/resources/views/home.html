A web framework for Rust

Laravel's productivity, Rust's performance, one binary to deploy.

Routing, sessions, a model layer and migrations, validation, auth, a queue and a scheduler, mail, storage, a UI kit and a data grid: everything a business app needs, in one renox dependency. Pages are rendered on the server and htmx swaps them in, with no Node build.

Start the tutorial Coming from Laravel

Quick start

cargo install renox-cli --version 1.0.0-rc.1   # installs `rnx`
rnx new blog && cd blog                          # or: --starter, --database postgres, --tailwind
rnx serve                                        # http://127.0.0.1:3000

Using Claude Code or another coding agent? Every new app has an AGENTS.md and a CLAUDE.md that tell it how Renox works; see the overview.
